# 路线图

M0 到 M6 已完成并验证。

V1 一致性检查将审计这些里程碑并扩展其评估，不新增里程碑。结果与可重现性：[基准测试](benchmark.zh-CN.md)。

<a id="m0--modélisation-du-problème"></a>
## M0 — 问题建模

定义模拟和策略共用的模型。

- [x] 定义环境、代理、任务和共享资源。
- [x] 形式化移动、容量和资源使用约束。
- [x] 定义模拟实例的格式。

<a id="m1--moteur-de-simulation"></a>
## M1 — 模拟引擎

在离散环境中执行可重现的模拟。

- [x] 实现离散环境和障碍物。
- [x] 表示机器人、任务和移动行为。
- [x] 管理对共享资源的访问。
- [x] 加载模拟实例。
- [x] 确保可重现性，特别是通过随机种子控制。
- [x] 使用 pytest 测试模拟引擎的行为。

<a id="m2--allocation-centralisée"></a>
## M2 — 集中式分配

开发并比较集中式分配与调度策略。

- [x] 实现启发式基线 FIFO。
- [x] 实现使用 OR-Tools CP-SAT 的优化。
- [x] 在共同实例上比较不同分配方案。

<a id="m3--coordination-multi-agent"></a>
## M3 — 多智能体协调

允许代理进行协商并分配任务。

- [x] 实现代理的本地决策。
- [x] 增加代理间的通信功能。
- [x] 实现合同网协议（CNP），从任务发布到任务分配。
- [x] 将协商功能集成到模拟引擎中。

<a id="m4--environnement-dynamique"></a>
## M4 — 动态环境

使决策能够适应模拟过程中的变化。

- [x] 处理新任务的到达。
- [x] 处理机器人不可用的情况。
- [x] 根据扰动调整分配和计划。

<a id="m5--benchmark-et-évaluation"></a>
## M5 — 基准测试与评估

在相似条件下评估策略表现。

- [x] 定义实验场景和评估指标。
- [x] 使用已实现策略执行可重现的实验。
- [x] 在相同场景下比较不同策略。
- [x] 分析并记录实际获得的结果。

<a id="m6--interface-web-interactive"></a>
## M6 — 交互式网页界面

使用 Vue 3、TypeScript、SVG 和 FastAPI 探索模拟并创建实例。

- [x] 可视化仓库、障碍物和机器人。
- [x] 重放模拟并展示代理间的交互行为。
- [x] 可读、暂停、调节速度并本地导航到快照。
- [x] 选择机器人、任务和站点；查看当前时间步的运行状态、分配、占用情况和历史记录。
- [x] 提供一个持久的图例、任务过滤器，并区分Python路径与收集/交付关系。
- [x] 允许选择已实现的策略。
- [x] 创建自定义实例：机器人、能力、任务、障碍物、维度和资源。
- [x] 以M0定义的格式导入和导出实例。
- [x] 可视化模拟和对比结果。
- [x] 自动显示一个持久的对比结果，包含M5指标、错误以及过期结果的无效性。
- [x] 提供一个可复现的复杂实例，测量三种策略之间的操作差异。
- [x] 生成具有固定维度和本地种子的、有效的随机实例，可编辑且可导出。
- [x] 用本地API和反应式前端替代Streamlit，而不修改科学引擎。

<a id="v2-scientifique--terminée"></a>
## V2 科学——已完成

<a id="m7--advanced--robust-scheduling"></a>
### M7 — 高级与稳健调度

评估时间安排、滑动时间范围和鲁棒性在有限场景下的表现。

- [x] 使用CP-SAT建模优先级、路径、能力、站点、到达和延迟；最小化总延迟后最小化makespan。
- [x] 在V1引擎中回放计划：保留优先级ID、延迟释放和预留状态在暂停期间。
- [x] 在无未来事件的情况下重新规划，任务被揭示，待办事项被保留，活跃承诺被冻结。
- [x] 通过最小最大法优化固定队列：先最小化最坏延迟，再最小化最坏makespan，确保每个声明日历中的完成；仅对列举的场景和策略提供保障。
- [x] 通过oracle验证微案例，区分状态和预算，基于明确信息对比基线，并发布[可复现的结果](results/v2/m7.json)。

<a id="m8--distributed-constraint-optimization"></a>
### M8 — 分布式约束优化

评估通过局部决策和代理间交换实现的分布式分配。

- [x] 在任务/等待域、私有成本和目标基数与成本上实现DSA，不使用隐藏的中央优化。
- [x] 通过消息确认分配，避免重复且不依赖引擎的拒绝机制。
- [x] 通过枚举和CP-SAT验证分配；在[可复现的结果](results/v2/m8.json)中对比FIFO/CNP、振荡、预算、消息和完整时间。
- [x] 验证实验性扩展Ollama：实现真实、合法且可追溯的局部决策，模型在验证后独立测试；基数低于参考值（[证明](results/v2/ollama-selection-20261015/report.json)）。

<a id="m9--multi-agent-path-finding"></a>
### M9 — 多智能体路径寻找

在孤立的MAPF场景中为固定目的地规划兼容路径。

- [x] 形式化运动、等待、顶点冲突和边交换，包含吸收性且持久的目标。
- [x] 实现优先级规划、预订和CBS；独立验证计划，并与完备oracle的最优解进行对比。
- [x] 将证书限制在声明的模型和时间范围内；区分在时间范围内的不可行性、优先级失败和预算耗尽。
- [x] 在[可复现结果](results/v2/m9.json)中比较成本、成功率、优先级和预算，不修改物理V1模型。

<a id="m10--cooperative-multi-agent-reinforcement-learning"></a>
### M10 — 合作多智能体强化学习

在有限的表格领域内评估合作分配学习。

- [x] 重用V1引擎，结合局部观测、动作掩码和比较策略间的共享信息。
- [x] 在剩余揭示任务、状态转移、终止条件和水平截断上测试共同奖励。
- [x] 训练表格Q学习器，保存和加载策略；分离训练、验证和测试阶段，仅在验证阶段进行策略选择。
- [x] 在多个种子上评估固定策略对启发式方法的表现；将泛化失败的负结果保留在[可复现结果](results/v2/m10.json)中。
- [x] 验证Ollama实验扩展：真实、合法且可追溯的动作，模型在验证阶段选择并在测试阶段独立测试，未证明具有普遍优势（[证据](results/v2/ollama-selection-20261015/report.json)）。
